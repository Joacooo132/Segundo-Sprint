Preguntas frecuentes

Calidad¿QA y testing significan lo mismo?

No. El aseguramiento de calidad (QA) se centra en dar confianza en los procesos: estándares, revisiones y prevención. El testing evalúa productos de trabajo y software para aportar información sobre calidad y riesgos. Se complementan; probar al final no sustituye un proceso cuidado.

Calidad¿Qué diferencia hay entre verificación y validación?

Verificar es comprobar el cumplimiento de requisitos especificados. Validar es comprobar que se resuelve la necesidad de uso. Ejemplo: el formulario puede guardar exactamente los campos definidos (verificación), pero no servir para que un estudiante se inscriba sin ayuda (validación).

Metodologías¿Cuándo conviene Scrum y cuándo Kanban?

Scrum aporta un objetivo y una cadencia de inspección para desarrollar productos complejos con un equipo estable. Kanban encaja especialmente bien cuando llega trabajo continuo y variable, como soporte o mantenimiento. Observa el tipo de demanda y la capacidad; no elijas solo por el tamaño del equipo.

Metodologías¿Se pueden combinar enfoques tradicionales y ágiles?

Sí. Por ejemplo, hitos de aprobación del proyecto con desarrollo incremental, o Scrum con prácticas de XP. Explicita qué problema resuelve cada práctica y revisa tensiones: un alcance fijo no se vuelve adaptable solo por usar un tablero.

Estándares¿Qué estándares ISO debería conocer primero?

ISO 9001 trata sistemas de gestión de calidad; ISO/IEC 25010 ofrece modelos de calidad del producto. Consulta la edición aplicable en iso.org. Leer una norma no equivale a obtener una certificación y el uso de una norma no garantiza por sí solo software sin fallos.

Primeros pasos¿Cómo empiezo si todavía no tengo experiencia?

Elige un caso cercano: una inscripción a cursos. Describe la necesidad, define criterios de aceptación y dibuja el flujo. Después escribe pruebas y elige una práctica para mejorar. Usa los ejercicios del sitio para contrastar tu razonamiento, no para memorizar etiquetas.
